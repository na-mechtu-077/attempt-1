# Messages / Instructions

## Роли сообщений
- **system**: задаёт поведение ассистента (глобальные инструкции).
- **user**: сообщение от пользователя.
- **assistant**: ответ модели (используется в многопоточных диалогах).

## Формат
```json
{"role": "system", "content": "Ты — полезный ассистент."}
{"role": "user", "content": "Привет!"}

## Инструкции (Instructions)

- Чётко прописывайте желаемое поведение в system.
- Используйте few-shot примеры в user/assistant для улучшения качества.
- Для сложных задач разбивайте инструкцию на шаги.
- Указывайте формат вывода (JSON, Markdown, список и т.д.).
