# System / Developer / User

## System (Системная роль)
- Задаёт **контекст и правила** для всей беседы.
- Пример: *"Ты — эксперт по Python. Отвечай только на русском."*
- Влияет на тон, стиль и ограничения.

## Developer (Разработчик)
- Не является стандартной ролью OpenAI.
- В контексте API — это **вы** (инженер), настраивающий промпты и логику.
- Отвечает за валидацию входных/выходных данных.

## User (Пользователь)
- Конечный пользователь, который задаёт вопросы.
- Сообщения этой роли — основной драйвер диалога.

## Важно
- Порядок сообщений должен соблюдать хронологию.
- System-сообщение должно идти **первым** (если используется).
