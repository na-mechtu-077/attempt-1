# Обработка ошибок

## Коды HTTP
- **400 Bad Request**: неверный JSON или параметры.
- **401 Unauthorized**: невалидный API-ключ.
- **429 Too Many Requests**: превышен лимит запросов.
- **500 Internal Server Error**: проблема на стороне OpenAI.

## Типичные ошибки
- `insufficient_quota`: закончились средства на аккаунте.
- `context_length_exceeded`: диалог слишком длинный.
- `rate_limit_exceeded`: слишком частые запросы.

## Стратегии
- Используйте **try/except** в коде.
- Внедряйте **exponential backoff** для повторов при 429/500.
- Логируйте ошибки с деталями (статус, сообщение).
- Для длинных диалогов реализуйте усечение истории.
