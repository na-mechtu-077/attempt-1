# Параметры модели

## Основные параметры
- **model**: `gpt-4o`, `gpt-4-turbo`, `gpt-3.5-turbo` и др.
- **temperature** (0–2): степень случайности. Чем выше, тем креативнее.
- **max_tokens**: максимальная длина ответа в токенах.
- **top_p** (0–1): альтернатива temperature (ядро вероятности).
- **n**: количество вариантов ответа (по умолчанию 1).

## Дополнительные
- **stop**: список строк, при появлении которых генерация прекращается.
- **presence_penalty** / **frequency_penalty**: штрафы за повторяемость.
- **response_format**: `{ "type": "json_object" }` — принудительный JSON.

## Советы
- Для точных задач используйте `temperature=0`.
- Для творческих — `0.7–1.0`.
- Следите за лимитом `max_tokens`, чтобы не обрезать ответ.
