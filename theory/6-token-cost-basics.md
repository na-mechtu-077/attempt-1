# Token / Cost Basics

## Что такое токен?
- Единица текста: ~4 символа на английском, ~1 слово.
- Для кириллицы 1 токен ≈ 1–2 символа.
- Токены считаются отдельно для **входа** (prompt) и **выхода** (completion).

## Стоимость (на примере GPT-4o)
- **Input**: ~$5.00 / 1M токенов
- **Output**: ~$15.00 / 1M токенов
- Цены меняются, проверяйте на [openai.com/pricing](https://openai.com/pricing).

## Как экономить?
- Укорачивайте системные промпты.
- Устанавливайте `max_tokens` по минимуму.
- Кэшируйте частые запросы.
- Используйте более дешёвые модели (GPT-3.5-turbo) для простых задач.

## Мониторинг
- Поле `usage` в ответе показывает точное потребление.
- Настройте алерты в аккаунте OpenAI.
